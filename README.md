# FutuQuant - 富途量化数据平台

A500 ETF 量化交易系统，基于 Futu OpenD + PySide6。

## 快速开始

```bash
git clone https://github.com/eaglefly628/futuProject.git
cd futuProject
pip install -e .

# 启动 Futu OpenD 后运行
python main.py
```

## 自动行情与指数对照

运行 `python main.py --market` 直接打开「A500中心 → 全市场对照」。
应用启动时分页扫描全市场 ETF 名单，只纳入普通中证A500 ETF，排除增强、红利、低波和联接基金，
并缓存名单用于断网启动；每 24 小时更新名单。当前名单来源为东方财富 ETF 市场。

同时同步上证综指、深证成指、沪深300、中证A500指数。
启动时更新一次行情与日线/60分钟线；工作日 9:15–11:30、13:00–15:10，
报价每 3 秒、历史 K 线每 10 分钟在后台更新，包含收盘后的补齐窗口。
节假日可能仍发起请求，以数据源返回的行情时间为准。
可通过「自动更新」开关暂停，也可以「立即同步」更新数据。
关闭应用后停止采集；免费源的分钟历史可能不完整。

对照页可选择 1/5/20/60 交易日窗口和指数基准，展示窗口价格收益、
超额收益（百分点）、上涨家数和跑赢基准家数；走势图使用相同交易日并将起点归一到 100。
缺失或历史不足显示 `—`，不把旧行情填为零收益。价格收益未计分红、费用，
指数仅作为对照基准与走势图，不参与基金排名。
可按超额收益或绝对偏离排序。偏离排名反映过去价格表现，不是买入评分；筛选按行情简称识别。
运行 `python -m scripts.analyze_market --days 20` 导出全部普通A500 ETF 相对四个指数的收益与排名 CSV，
结果保存在 `data/reports/`。

## 净值折溢价

运行 `python main.py --value` 打开「A500中心 → 净值折溢价」。
仅比较普通A500 ETF，展示成交价、IOPV、卖一价、相对IOPV的偏离、买卖价差、成交额、正式净值及日期、年费率摘要。
偏离统一用 `(价格 / 参考净值 - 1) × 100%`：负数折价、正数溢价。
卖一价偏离与最后成交价偏离分别排序，避免将已成交的低价当成可以买到的报价。
正式净值若与价格日期不同，不计算净值折价。

IOPV与盘口来自东方财富指定ETF批量行情，交易时段每分钟更新；正式净值与费率摘要每30分钟更新。
IOPV接口未单独提供时间戳，数据只能用于参考筛查，盘后报价不能视为可执行价格。
正式净值由东财转录，费率摘要标记为待官方核验；560530另外查询摩根基金官方费率页。
佣金与实际成交滑点未计入，不自动输出买入建议。
运行 `python -m scripts.analyze_value` 导出全部普通A500 ETF 的快照CSV和带来源链接的JSON至 `data/reports/`。

## A500 量化中心

启动 GUI 后点击侧栏 **🎯 A500中心**，四个标签页覆盖全部操作：

| 标签页 | 功能 |
|--------|------|
| 📈 K线图表 | 蜡烛图 + 成交量 + MA5/10/20/60，滚轮缩放，十字光标看OHLC |
| 🔬 量价分析 | 评分仪表盘、五因子柱状图、涨跌概率、支撑阻力、分析信号 |
| ⬇️ 数据采集 | 勾选周期 → 一键采集，实时进度条 + 本地数据覆盖表 |
| 📊 全市场对照 | 全部普通A500 ETF 相对指数的收益与偏离排序 |

顶部工具栏可切换自动更新的普通A500 ETF 名单和周期（1分钟~日线）。

> 也保留了命令行方式：`python -m scripts.fetch_a500` / `python -m analysis.a500_analyzer SZ.159338`

## 项目结构

```
futuProject/
├── main.py              # GUI 入口
├── pyproject.toml        # 项目配置 (pip install -e .)
├── config/default.yaml   # 运行配置（费率/刷新间隔等）
├── core/                 # OpenD 客户端 + 实时行情订阅
├── downloaders/          # K线下载 + 逐笔采集
├── storage/              # SQLite 数据库 (WAL模式)
├── trading/              # 模拟交易引擎 + 费用计算
├── strategy/             # 策略引擎 + 回测 + 技术指标
├── analysis/             # 数据质量 + A500量价分析
├── gui/
│   ├── panels/           # 13个功能面板（含A500中心）
│   └── widgets/chart.py  # K线图/柱状图/仪表盘（纯QPainter）
├── scripts/              # 批量采集脚本
└── docs/                 # Futu API 文档
```

## 功能

| 模块 | 说明 |
|------|------|
| A500中心 | K线图表 + 量价分析 + 数据采集 一体化面板 |
| 实时行情 | 3秒刷新 + 价格预警 |
| 模拟交易 | 全市场CNY统一账户，A股/港股/美股真实费率 |
| 策略编辑 | 可视化条件 + Python脚本双模式 |
| 回测 | 收益率/回撤/夏普/胜率 |
| A500分析 | 5因子趋势预测 + 量价结构 + 支撑阻力 |
| 数据采集 | K线(9周期) + Tick，增量下载 |

## 依赖

Python >= 3.10 + Futu OpenD（本地）
